Como registrar o consumo parcial

Dica da Eva: cozinhe primeiro. Se estiver com as mãos molhadas ou sujas, anote no papel o que usou, como dois cubos de caldo, meio litro de leite ou 250 g de macarrão. Depois dê baixa nas unidades inteiras e use Consumo parcial para registrar o que restou. Até atualizar, o inventário e as sugestões podem estar desatualizados.

Ajuste o controle para a quantidade restante. 100% é inteiro, 50% é metade e 0% é vazio. Nas formas compatíveis, também dá para tocar no desenho. O valor é uma estimativa. O controle vale para uma unidade. De doze garrafas, onze inteiras e uma com 50% aparecem separadas. Você pode escolher onde guardar a que foi aberta.

Toque para salvar, confira o resumo e confirme. Para retirar unidades inteiras, informe quantas e vá ao resumo antes de confirmar. O resumo informa se vai acrescentar uma compra. Linhas criadas por movimentação ou abertura de embalagem não geram uma compra para cada unidade. Se errou, veja Últimas 15 operações. Desfazer uma operação disponível corrige também a lista de compras afetada.
