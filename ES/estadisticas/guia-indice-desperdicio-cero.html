Guía: índice de desperdicio

El índice de desperdicio indica Aún no se puede calcular. Para obtener porcentajes fiables hay que distinguir entre productos consumidos y productos desechados. Las salidas aún no registran esta diferencia.

Una fecha superada no significa automáticamente que se haya tirado el producto. Las existencias actuales no demuestran que todo lo demás se haya consumido a tiempo. No se asignan porcentajes ni niveles de eficiencia mientras falten estos datos.
