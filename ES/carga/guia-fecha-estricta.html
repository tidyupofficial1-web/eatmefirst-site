Fecha estricta

Marca esta opción para una fecha que no se debe posponer. Debes indicar una fecha. Las fechas orientativas o estimadas se distinguen de las estrictas.

Los avisos empiezan diez días antes: rojo para fechas estrictas y amarillo para orientativas. Las fechas más lejanas se muestran sin resaltar. Las superadas se destacan. La app no determina la seguridad de los alimentos: respeta el etiquetado y las condiciones de conservación.
