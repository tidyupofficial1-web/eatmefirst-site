# EatMeFirst

Website and browser application for organising household supplies, expiry dates,
usage and shopping lists. Available in Italian, English, French, German and Spanish.

Open the website: https://tidyupofficial1-web.github.io/eatmefirst-site/

Inventory changes are stored locally in the browser on the device being used.
Export and import transfer a file manually; devices do not synchronise automatically.
The educational game uses example products.
