💡 Vos réserves, aussi sur un autre appareil
L’application enregistre automatiquement les modifications sur cet appareil. Dans Utilitaires, vous pouvez exporter vos réserves dans un fichier et le conserver séparément, puis le transférer et l’importer sur un autre appareil. Le transfert est manuel : les appareils ne se synchronisent pas automatiquement. L’exportation est actuellement gratuite.
