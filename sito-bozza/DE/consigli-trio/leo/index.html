Tipps von Leo

Dateien, Sicherungen und Handy-Einstellungen

Leo eine Frage stellen

  • Kamera im Browser geht nicht? So gibst du sie wieder frei

    Prüfe die Berechtigungen in Chrome auf Android oder Safari auf dem iPhone, bevor du einen Barcode scannst.

  • Was liest das Handy aus einem Lebensmittel-Barcode?

    Woher stammen Zutaten und Kalorien, wenn du eine Verpackung scannst?

  • Wie Sie eine Website zum Startbildschirm hinzufügen

    Öffnen Sie die Website in Ihrer Internet-App, etwa Chrome, Edge oder Safari.

  • Wo Sie Downloads auf dem Handy finden

    Öffnen Sie auf dem iPhone Dateien und suchen Sie unter Durchsuchen nach Downloads.

  • Was es bedeutet, Daten im Handy-Browser zu speichern

    Ihre Vorräte bleiben normalerweise im selben Profil und Browser auf demselben Gerät.

  • Wie Sie Sicherungsdateien benennen und schnell wiederfinden

    Nutzen Sie ein einheitliches Format wie vorrat-2026-11-25-handy.

  • Produktnotizen: Zutaten und selbst gemachte Speisen.

    Eine kleine Notiz erspart späteres Rätselraten.

  • Handy oder PC kaputt? Vorräte wiederherstellen.

    Jetzt kommt die externe Kopie ins Spiel. Leo erklärt den Neustart.
