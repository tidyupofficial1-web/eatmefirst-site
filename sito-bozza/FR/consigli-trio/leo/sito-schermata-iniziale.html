Comment ajouter un site à l’écran d’accueil sur iPhone ou Android

Créez une icône pour ouvrir EatMeFirst d’un toucher depuis l’écran d’accueil du téléphone.

Sur Android, ouvrez le menu du navigateur

Ouvrez le site dans un navigateur comme Chrome ou Edge. Dans Chrome, touchez les trois points et choisissez l’option d’ajout à l’écran d’accueil. Si « Créer un raccourci » s’affiche, choisissez cette option et confirmez. Dans Edge ou un autre navigateur, cherchez une option similaire. Dans les versions récentes de Chrome, cette commande peut s’appeler « Installer et créer un raccourci ».

Sur iPhone, utilisez Partager dans Safari

Ouvrez le site dans Safari, puis touchez Partager, directement ou depuis le menu de la page. Choisissez « Sur l’écran d’accueil », puis « Ajouter ». L’icône permet de retrouver EatMeFirst, votre garde-manger et vos courses. Si vous changez de navigateur ou de façon d’ouvrir le site, vérifiez que vos données apparaissent. L’inventaire, la liste et l’enregistrement automatique sont gratuits. Vous pouvez commencer dans le navigateur, sans installation ni inscription.
