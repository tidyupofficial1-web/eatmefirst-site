À quoi sert un code EAN ?

Il identifie le produit, par exemple un yaourt d’une marque et d’un format précis. Des pots identiques portent le même code même si leurs dates diffèrent.

D’où viennent les ingrédients et les calories ?

Quand vous recherchez un aliment en ligne dans EatMeFirst, le code sert à trouver sa fiche dans Open Food Facts. Si la fiche contient les ingrédients ou les valeurs nutritionnelles, l’application peut les afficher. Vérifiez les informations manquantes sur l’emballage, surtout les allergènes. Pour la date, lisez celle inscrite sur votre pot.
