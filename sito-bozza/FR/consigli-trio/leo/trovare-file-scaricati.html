Où trouver les fichiers téléchargés sur iPhone et Android

Retrouvez vos téléchargements dans l’application de fichiers ou le navigateur, y compris la copie exportée d’EatMeFirst.

Sur iPhone, cherchez dans Fichiers ou dans Safari

Ouvrez Fichiers, touchez Explorer, puis cherchez Téléchargements. Si le dossier n’apparaît pas, regardez dans iCloud Drive. Son emplacement peut dépendre des réglages de Safari. Si vous venez de télécharger un fichier dans Safari, touchez aussi le bouton Téléchargements près du champ de recherche.

Sur Android, regardez dans le gestionnaire de fichiers ou dans Chrome

Ouvrez votre gestionnaire de fichiers, par exemple Files, puis cherchez Téléchargements. Si vous avez utilisé Chrome, ouvrez le menu à trois points et touchez Téléchargements. Après avoir exporté une copie EatMeFirst, retrouvez-la aussitôt et enregistrez-la à l’endroit choisi. L’inventaire, la liste et l’enregistrement dans le navigateur sont gratuits, sans installation ni inscription.
