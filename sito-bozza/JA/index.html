もうこんなことは起きてほしくない！

冷蔵庫を開けたら、食品が傷んでいた。そんなことはありませんか？ 別のパックの陰に隠れたまま、何日も経っていたのかもしれません。

こんなことを思ったことはありませんか？

家のストックを整理するアプリに、どんな機能がほしいですか？

食品だけでなく、洗剤やペット用品など、家のために買うものもあります。こんな希望を考えてみました。あなたも同じですか？

  • ✓

    面倒な登録をしたくない！

    「メールアドレスやGoogleアカウント、連絡先を渡したくない。新しいパスワードも作りたくない。」

    アカウントを作らずに、すぐ在庫管理を始められます。

  • ✓

    家のストックは手元に。

    「買ったものや数量、どれくらい使ったかを、自分のスマホに残しておきたい。」

    商品、数量、メモはスマホに残ります。在庫一覧が私たちに送られることはありません。バーコードで検索するときは、商品を探すためにそのコードを外部カタログに送ります。在庫の中身は送りません。

  • ✓

    使い方は分かりやすく。

    「詳しくなくても、何をすればいいか分かるといいな。」

    各機能でヘルプを確認できます。マックス、エヴァ、レオも、やさしい言葉と時々冗談を交えて案内します。

  • ✓

    バーコードのないものも登録。

    「市場の野菜や量り売りの品、自分で作った料理はどうするの？」

    ラベルがなくても、名前、数量、保管場所、必要なら日付を入力して登録できます。自家製ジャム、残った料理、小分けして冷凍したものも同じです。

  • ✓

    何がどこにあるか知りたい。

    「食品棚、冷蔵庫、物置。いちいち思い出さなくても見つけたい。」

    必要な保管場所や分類を設定できます。一つのパックから何個かだけ別の場所へ移し、どこに置いたか確認できます。

  • ✓

    使いかけの残りも記録。

    「サラミやボトルを半分使っても、残りはまだある！」

    個数を減らすことも、中身がどれだけ残ったか記録することもできます。開封しただけで在庫から消す必要はありません。

  • ✓

    先に使うものを思い出す。

    「冷蔵庫の奥に忘れる前に、期限が近いものに気づきたい。」

    在庫を期限順に表示し、近づくと知らせます。厳守する期限と、目安の日付を区別できます。

  • ✓

    買い物リストを一から作らなくていい。

    「使い切った品を見つけ、思いついたものも追加したい。」

    使い切ったと記録した品はリストに入ります。メモを加え、買い物中にチェックを付けられます。チェックした項目は暗くなり、取り消し線が付き、下へ移動します。

無料で使いたい！

はい。ここで紹介した機能は無料で使えます。30日間だけの体験版ではありません。

「何か裏があるんじゃない？」 今のところ広告も表示していません。今後表示する場合も、操作を邪魔しない形にしたいと考えています。

在庫の変更は、使っているスマホに自動で無料で保存されます。
