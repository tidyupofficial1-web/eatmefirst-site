How to recover your EatMeFirst pantry after a phone or computer breaks

Find the external backup, check what it contains before importing, and re-enter changes made since it was created.

Find the backup you saved somewhere else

If the old device no longer works, look for the file made with Export pantry. The default name begins EatMeFirst-dispensa and ends in .json. Check your computer, USB drive or an email you sent yourself. A copy kept only in another folder on the broken phone may be inaccessible.

If you find several copies, choose the one that contains the state you want to restore. The latest date or the greatest number of items doesn’t always tell you which one that is.

1. Transfer the file to the new device

Copy it from your drive or download the attachment on the new phone or computer. You can select the file from the app without opening or editing it first.

2. Open EatMeFirst

Use the app link from the official website. On a new device you may see the introduction and terms again. Read them and, if you accept them, tick the box and continue to the Menu. Your choice on the old phone isn’t carried over.

3. Open Utilities and choose Import pantry

Select the file. The app shows a preview before replacing any data. Compare what’s in the file with what’s on the device and confirm only if you want to restore that state. Import replaces the whole inventory; it doesn’t merge copies.

Say the backup holds 100 products and you’ve only entered today’s milk on the new phone. Before importing, write down the milk and any other new entries. If you export them, save that as a separate file with a different name so it doesn’t overwrite the 100-product copy. Restore the 100 products, then enter the milk again. Importing the milk-only file afterwards would remove the other products again.

4. Check Inventory and the shopping list

Check products, quantities, dates and notes. Images linked from external catalogues may need an internet connection. Think of an older backup as a snapshot. A milk purchase or pasta you used after exporting it won’t be in the file. Reconcile the restored figures with what you actually have. The dates on the products stay as recorded.

If you don’t have an external copy

Look on another phone or computer you used with EatMeFirst. If it still has a useful inventory, export it from there. If the broken device can’t be recovered and there’s no copy, you’ll need to enter the products again. EatMeFirst has no pantry backup on its servers to send back. If you want to recover the old device, ask a technician before resetting it or erasing its data. The result depends on the fault.

Keep the next copy away from the device

Confirmed edits save automatically in the browser on the device you’re using. Exporting a file and keeping it somewhere else is a separate step. Do it after major changes, and if you use two devices, transfer the copy from the one with the state you want. Changes made separately don’t merge. As Eva says, keep the spare key outside the house when you lock yourself out.
