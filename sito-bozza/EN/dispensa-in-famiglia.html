How to share one EatMeFirst pantry with your family

Eva explains how to pass an up-to-date inventory file between phones and a computer.

Start with one agreed place

Eva had recorded the shopping and Max had recorded what they used, but some things went missing and others reappeared. Each person was opening a different file from Downloads, email or the family laptop. Agree where the current copy lives, such as a shared folder, a USB drive or a service you choose.

Import before you start and export when you finish

Tell the family when you are about to use the inventory. Take the current file from the agreed location and compare the import preview before confirming. When you finish, export a copy, check that it downloaded and return it to that location. Then tell whoever is next.

Recognise the file before replacing the inventory

Give the files recognisable names, such as Eva-phone or Max-laptop, and check the date and the import preview. A file downloaded again today still contains the older data. Check any warnings. If the browser adds (1), verify which file is current before moving older copies into a separate folder.

Take turns

EatMeFirst does not upload files to Drive automatically, show who is editing on another device or merge separately edited inventories. Everyone who uses a shared online folder needs access and a connection. If you have changes that have not been exported, save them before importing another copy.

Guide to utilities and backups

A single place for the latest copy

Eva, Max, their two children and Leo agreed on a simple routine for four phones and the household laptop. Before making changes, take the latest file from the agreed place, open Import pantry and check the preview. When you finish, export, check that the download completed, put the file back in that place and tell the next person. Take turns so that two people do not edit separate copies.

Which copy should we use?

Imagine a file Eva saved on 12 December and one Max saved on 13 December. Ask whether Max also recorded what he used the night before. A name helps identify who exported a copy. The dates here are examples. Downloading a file again today does not make its data newer. Read the preview and any warnings before replacing the current pantry.

Where to keep the file

Use a family folder, a USB drive you pass around or a service such as Google Drive. Upload the file yourself and check that the upload finished and the next person has access. EatMeFirst does not upload or synchronise it. A browser may add “(1)” to a duplicate filename. Check the latest file before putting the older one aside, and keep old copies in a separate folder.

A family meeting with Leo

Eva called Max, their two children and Leo to the table. Max asked whether there would be anything to eat. “First we’ll get the pantry records straight,” Eva said, “then we’ll see what to cook.” Four phones and the family laptop were in use. They agreed to use one current copy and pass it from one person to the next.

Set the name used when you export

In Utilities, choose Device name and backup help and enter a label such as “Eva — phone” or “Max — laptop”. The browser can remember it for future exports. The name appears in the filename and the import preview, where the recipient can read it. Before replacing the pantry, check the preview and any warnings. Downloading an old copy again does not update its contents.
