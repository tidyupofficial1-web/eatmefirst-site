All tips from Leo

How to name backup files so you can find the latest copy

Put the date and device in the filename, keep the extension and check the copy before importing it.

Use one naming pattern for all copies

A name such as pantry-2026-11-25-phone.json tells you what the file contains, which device it came from and when it was exported. If you rename it, keep the file extension and store your copies in a dedicated folder.

Check the copy before you use it

If you save from several devices, compare the filename dates. When importing, review the preview and the date the data was last changed. The export date and the last edit date can differ.
