Dove trovare i file scaricati su iPhone e Android

Cerca i download nell’app File o nel browser e ritrova la copia di EatMeFirst dopo averla esportata.

Su iPhone, cerca in File o in Safari

Apri File, tocca Sfoglia e poi Download. Se non vedi la cartella, guarda in iCloud Drive. La posizione può dipendere dalle impostazioni di Safari. Se hai appena scaricato il file con Safari, puoi anche toccare il pulsante Download vicino al campo di ricerca.

Su Android, cerca nei file o nel menu di Chrome

Apri l’app che gestisce i file, per esempio Files, e cerca Download. Se hai usato Chrome, apri il menu con i tre puntini e tocca Download. Quando esporti una copia di EatMeFirst, cercala subito e fanne una copia nel posto in cui vuoi conservarla. Scorte, lista e salvataggio nel browser sono gratuiti, senza installazione o registrazione.
