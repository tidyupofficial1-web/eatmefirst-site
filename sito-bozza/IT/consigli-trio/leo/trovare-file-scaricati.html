Dove trovare i file scaricati sul cellulare

Su iPhone, aprite l’app File e cercate la cartella Download in Sfoglia. La posizione può dipendere dalle impostazioni di Safari.

Su Android potete partire dall’app che gestisce i file e cercare Download. Se avete scaricato il file con Chrome, potete anche aprire il menu di Chrome e scegliere Download.

Prova con EatMeFirst

Se avete esportato una copia di EatMeFirst, cercatela subito dopo il download e conservatene una copia nel posto che avete scelto.

EatMeFirst salva le scorte e la lista gratuitamente nel browser. Puoi iniziare senza scaricare nulla e senza registrarti.
