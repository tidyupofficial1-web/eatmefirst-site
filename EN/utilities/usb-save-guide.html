Saving and keeping a spare copy

Confirmed changes are saved in the browser on both PC and phone. Press Save or Confirm when the operation requires it. Typing in a field alone does not save it.

Export inventory downloads a file containing products, catalogue, lists, notes, reminders, preferences and the last 15 operations. Noticeboard photos are included; online product images remain source links.

Keep a copy outside the device, such as a USB drive or another device. Plugging in a USB drive does not start a backup. You can attach the exported file to an email yourself; EatMeFirst does not send it automatically.

Import inventory shows a preview before replacing anything. Compare the current and incoming situations. A newer date alone cannot combine changes from two devices. Import replaces the complete situation.

Before replacement, one local recovery copy is kept. Recover opens its preview; confirm only if it is the situation you want. This copy stays in the same browser and does not protect against device failure.

The basic app remains free; the external backup service is the planned paid service. Payment activation is still being completed. A backup can restore only changes included when it was exported.
